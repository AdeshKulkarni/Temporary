How this works for the Checker:
 * When the Checker opens a failed batch, the React code checks the workflowHistory.
 * Because the backend logged "Execution Failed", the UI instantly hides the "Approve/Reject" buttons.
 * Instead, it displays a single, full-width orange "Retry Approval" box.
 * The Checker clicks "Retry Approval", enters their remarks, and clicks "Confirm & Submit". It will trigger the exact same API to safely try again!
