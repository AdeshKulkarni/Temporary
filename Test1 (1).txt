Why this happened
In the last step, we surgically removed the highly vulnerable and ancient org.codehaus.jackson (Jackson 1.x) library from your project to pass the security scan.
However, your RequestStatus.java file was still explicitly importing the @JsonCreator annotation from that old, deleted library instead of using the modern, secure Jackson library (com.fasterxml.jackson) that Spring Boot naturally provides.
The Fix
Step 1: Open this specific file:
src/main/java/com/fincore/VoucherService/Models/enums/RequestStatus.java
Step 2: Look at the top of the file for the import statements.
REMOVE any imports that look like this:
import org.codehaus.jackson.annotate.JsonCreator;
import org.codehaus.jackson.annotate.JsonValue; // (If present)

REPLACE them with the modern Jackson 2.x/3.x equivalents:
import com.fasterxml.jackson.annotation.JsonCreator;
import com.fasterxml.jackson.annotation.JsonValue;

Step 3: Check for other stragglers
Before you commit and push to your CI/CD pipeline again, I highly recommend doing a Global Search (Ctrl+Shift+F or Cmd+Shift+F) in your IDE for the phrase:
org.codehaus.jackson
If any other files (like DTOs or other Enums) are using those old imports, change them to com.fasterxml.jackson.annotation.* exactly like we did above. Once those imports are swapped, your build will compile successfully and pass the security scan!
