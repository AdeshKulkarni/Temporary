To make the CGL field automatically snap to the correct entry when the user types 10 digits and then clicks away, presses Tab, or hits Enter, we need to apply the exact same onBlur treatment we gave the Branch field, and expand your existing onKeyDown logic to listen for the "Enter" key.
Here is the exact fix for **VoucherPosting.js**.
Find your **CGL** <Autocomplete> component and locate the onKeyDown property.
**Replace this block:**
```javascript
                            // --- ADDED INTERCEPTOR FOR TAB KEY ---
                            onKeyDown={(e) => {
                              if (e.key === 'Tab' && !row.cgl && cglSearch.options?.length > 0) {
                                // Automatically set the first suggestion when Tab is pressed
                                handleRowChange(row.id, "cgl", cglSearch.options[0]);
                              }
                            }}

```
**With this:**
```javascript
                            // --- ADDED INTERCEPTOR FOR TAB & ENTER KEY ---
                            onKeyDown={(e) => {
                              if ((e.key === 'Tab' || e.key === 'Enter') && !row.cgl && cglSearch.options?.length > 0) {
                                // Automatically set the first suggestion when Tab or Enter is pressed
                                handleRowChange(row.id, "cgl", cglSearch.options[0]);
                              }
                            }}
                            // --- ADDED ONBLUR FOR CLICK-AWAY ---
                            onBlur={() => {
                              const typedValue = cglInputValues[row.id];
                              if (!row.cgl && typedValue && typedValue.length === 10) {
                                // If they typed exactly 10 digits, grab the exact match (or the first/only available option from the DB)
                                const match = cglSearch.options.find(opt => String(opt.cglNumber) === typedValue) || 
                                              (cglSearch.options.length > 0 ? cglSearch.options[0] : null);
                                if (match) {
                                  handleRowChange(row.id, "cgl", match);
                                }
                              }
                            }}

```
With this added, if a user rapid-fires a 10-digit CGL and clicks on the Amount field, the CGL will lock in perfectly behind them.
