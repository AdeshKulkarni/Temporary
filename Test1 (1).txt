To ensure that every image inserted into your Quill/ReactQuill editor automatically appears with a width and height of 100px, you need to handle the image rendering or insertion logic. There are two common approaches:

---

### **Option 1: Set Image Size via Quill Clipboard (Recommended)**

Override the Quill clipboard to set image dimensions when an image is pasted or dropped:

```js
import Quill from "quill";

// Custom Clipboard Module
const Clipboard = Quill.import('modules/clipboard');
class CustomClipboard extends Clipboard {
  async onPaste(e) {
    e.preventDefault();

    // Get plain text or HTML from clipboard
    const clipboardData = e.clipboardData || window.clipboardData;
    const text = clipboardData.getData('text/plain');
    const html = clipboardData.getData('text/html');

    if (html && html.includes('<img')) {
      // If there's an image, force width and height
      const modifiedHtml = html.replace(/<img([^>]*)>/g, '<img$1 width="100" height="100">');
      this.quill.clipboard.dangerouslyPasteHTML(this.quill.getSelection().index, modifiedHtml);
    } else {
      super.onPaste(e);
    }
  }
}
Quill.register('modules/clipboard', CustomClipboard, true);
```

Then in your ReactQuill component:

```jsx
<ReactQuill
  ref={bodyEditorRef}
  value={bodyContent}
  onChange={handleBodyChange}
  modules={{
    clipboard: true, // Use our custom clipboard
    // other modules
  }}
/>
```

---

### **Option 2: Use CSS to Force Image Size**

If you just want all images to appear 100x100px visually, add this CSS to your editor:

```css
.ql-editor img {
  width: 100px !important;
  height: 100px !important;
  object-fit: cover;
}
```

---

### **Option 3: Modify Delta/Image Handler**

If you have a custom image handler in your Quill modules config, update the Delta to add width/height attributes to images:

```js
const imageHandler = () => {
  const range = this.quill.getSelection();
  const value = prompt('Enter image URL');
  if(value){
    this.quill.insertEmbed(range.index, 'image', value, 'user');
    // Immediately set the width and height via format
    setTimeout(() => {
      const [img] = this.quill.scroll.descendant(Quill.import('formats/image'), range.index);
      if (img) {
        img.domNode.setAttribute('width', '100');
        img.domNode.setAttribute('height', '100');
      }
    }, 0);
  }
};
```

---

## **Summary**

- For **universal enforcement**, use the CSS approach.
- For **controlling inserted HTML**, override the clipboard or image handler as above.

**Choose the option that fits your setup.**
