Got it! You want to swap the signs so that negative amounts go to Debit and positive amounts go to Credit directly in the database procedure.
Here are the exact 2 places you need to change this inside your PROCESS_JOURNAL_BATCH Oracle procedure.
1. Fix the GL_TRANSACTIONS Insert
Scroll down to -- 1. Insert GL_TRANSACTIONS and look inside the inner SELECT statement.
FIND THESE EXISTING LINES:
            CASE WHEN REQ_AMOUNT > 0 THEN (REQ_AMOUNT * -1)   ELSE 0 END AS DEBIT_AMOUNT,
            CASE WHEN REQ_AMOUNT < 0 THEN ABS(REQ_AMOUNT) ELSE 0 END AS CREDIT_AMOUNT,

REPLACE THEM WITH THIS:
            CASE WHEN REQ_AMOUNT < 0 THEN ABS(REQ_AMOUNT) ELSE 0 END AS DEBIT_AMOUNT,
            CASE WHEN REQ_AMOUNT > 0 THEN REQ_AMOUNT ELSE 0 END AS CREDIT_AMOUNT,

2. Fix the VOUCHER_TRANSACTIONS Insert
Scroll down to -- 2. Insert VOUCHER_TRANSACTIONS and look inside the inner SELECT statement.
FIND THESE EXISTING LINES:
            CASE WHEN REQ_AMOUNT > 0 THEN (REQ_AMOUNT * -1)   ELSE 0 END AS DEBIT_AMOUNT,
            CASE WHEN REQ_AMOUNT < 0 THEN ABS(REQ_AMOUNT) ELSE 0 END AS CREDIT_AMOUNT,

REPLACE THEM WITH THIS:
            CASE WHEN REQ_AMOUNT < 0 THEN ABS(REQ_AMOUNT) ELSE 0 END AS DEBIT_AMOUNT,
            CASE WHEN REQ_AMOUNT > 0 THEN REQ_AMOUNT ELSE 0 END AS CREDIT_AMOUNT,

That is it! Just replace those two exact spots in the PL/SQL procedure, and the database will perfectly route the negative numbers to Debit and the positive numbers to Credit just like you requested.
