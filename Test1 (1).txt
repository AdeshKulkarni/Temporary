The issue you are seeing in image.png occurs because long, continuous strings (like "dddd...") don't have natural spaces, so the browser doesn't know where to wrap the text. This forces the container to stretch horizontally, breaking out of your UI. We can easily fix this using the CSS properties wordBreak: "break-word" and overflowWrap: "break-word".
To solve both the overflow issue and add the "Read More" functionality to your main table rows, follow these exact replacements:
Fix 1: Stop Text from Breaking Out of the Box
Find this section inside your SelectedVoucherCard component (around line 656).
Existing Code:
<Collapse in={!isLongDesc || isDescExpanded} collapsedSize={20}>
  <Typography variant="body2" sx={{ whiteSpace: "pre-wrap", lineHeight: 1.6, fontWeight: 400, color: "text.primary" }}>
    {desc}
  </Typography>
</Collapse>

Replace with:
<Collapse in={!isLongDesc || isDescExpanded} collapsedSize={20}>
  <Typography variant="body2" sx={{ whiteSpace: "pre-wrap", wordBreak: "break-word", overflowWrap: "break-word", lineHeight: 1.6, fontWeight: 400, color: "text.primary" }}>
    {desc}
  </Typography>
</Collapse>

Fix 2: Add "Read More/Less" to the Main Table Row
Because your table maps over multiple rows, the cleanest way to handle a "Read More" toggle for each specific row without triggering them all at once is to create a small, reusable component.
Step 2A: Add this new component
Paste this code right above export default function VoucherPosting() { (around line 77):
const ExpandableDescription = ({ description }) => {
  const [isExpanded, setIsExpanded] = useState(false);
  const desc = description || "No description provided for this voucher configuration.";
  const isLongDesc = desc.length > 100 || desc.split(/\r?\n/).length > 2;

  return (
    <Box sx={{ position: "relative" }}>
      <Collapse in={!isLongDesc || isExpanded} collapsedSize={20}>
        <Typography variant="body2" color="text.secondary" sx={{ whiteSpace: "pre-wrap", wordBreak: "break-word", overflowWrap: "break-word" }}>
          {desc}
        </Typography>
      </Collapse>
      {isLongDesc && (
        <Box sx={{ display: "flex", justifyContent: "flex-start", mt: 0.5 }}>
          <Button
            size="small"
            disableRipple
            onClick={(e) => {
              e.stopPropagation(); // Prevents the main row from collapsing when clicked
              setIsExpanded(!isExpanded);
            }}
            endIcon={isExpanded ? <KeyboardArrowUpIcon /> : <KeyboardArrowDownIcon />}
            sx={{
              p: 0,
              minWidth: "auto",
              textTransform: "none",
              fontWeight: 600,
              color: "primary.main",
              "&:hover": { background: "transparent", textDecoration: "underline" }
            }}
          >
            {isExpanded ? "Read Less" : "Read More"}
          </Button>
        </Box>
      )}
    </Box>
  );
};
