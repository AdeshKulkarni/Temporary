Here are the exact changes you need to make to your VoucherCommandService.java file.
Step 1: Add the Imports
At the top of your file, with your other imports, add these two lines:
import org.springframework.transaction.support.TransactionSynchronization;
import org.springframework.transaction.support.TransactionSynchronizationManager;

Step 2: Replace the Async Handoff
Scroll down to the createBatchFromCacheAsync method (around line 147).
FIND this exact block of code:
            // 6. ASYNC HANDOFF (Pass to background thread)
            asyncWorker.executeAsyncBatchCreation(batchId, journalPrefix, requestId, commonRemarks, creatorId, creatorRole, vid);

            return batchId;

REPLACE it entirely with this block:
            // 6. ASYNC HANDOFF (Pass to background thread ONLY after DB commit is successful)
            TransactionSynchronizationManager.registerSynchronization(new TransactionSynchronization() {
                @Override
                public void afterCommit() {
                    asyncWorker.executeAsyncBatchCreation(batchId, journalPrefix, requestId, commonRemarks, creatorId, creatorRole, vid);
                }
            });

            return batchId;

Save the file and restart your application. This guarantees the background thread will wait until the main database transaction is 100% committed before trying to read the VOUCHER_POSTING records, eliminating the EmptyResultDataAccessException race condition.
