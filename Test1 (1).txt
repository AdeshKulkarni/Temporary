The root cause of all these issues is **Insecure Direct Object Reference (IDOR)**, which the scanner labels as "Access Control: Database". This happens when user-supplied input (like an ID or a Submission ID) is used directly in a database query to view, update, or delete records without checking if the current user actually owns or has permission to access that specific record.
