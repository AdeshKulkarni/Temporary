# Detailed Implementation Guide: Centralized Security Validator

To resolve the 11 Data Flow / Access Control issues, you need to apply the new `CentralizedSecurityValidator` to the five service implementation files. By intercepting the data extraction before it hits the database queries, the SCA tool will recognize that the input is sanitized and validated.

### Step 0: Inject the Validator (Apply to ALL 5 Service Impl Classes)
In each of the five files (`LfarAudiServiceImpl`, `Lfar2ComplianceServiceImpl`, `Lfar2_1ServiceImpl`, `Lfar2ServiceImpl`, `Lfar3ServiceImpl`), add the autowired dependency at the top of the class:

```java
    @Autowired
    CentralizedSecurityValidator centralizedSecurityValidator;
```

---

### 1. `LfarAudiServiceImpl.java` (Fixes Issues 1, 5, 10)

**A. In `getData` method:**
*Find this (around line 52):*
```java
    String quarterEndDate = user.get("quarterEndDate");
    String reportId = (String) data.get("reportId");
    String submissionId = String.valueOf(data.get("submissionId"));
```
*Replace with:*
```java
    String quarterEndDate = user.get("quarterEndDate");
    String reportId = centralizedSecurityValidator.sanitizeId(data.get("reportId"));
    String submissionId = centralizedSecurityValidator.validateSubmissionAccess(data.get("submissionId"), user);
```

*Find this (inside the for-loop, around line 74):*
```java
    String tableId = String.valueOf(questionsData.get(i).get("LFAR_SEQ"));
```
*Replace with:*
```java
    String tableId = centralizedSecurityValidator.sanitizeId(questionsData.get(i).get("LFAR_SEQ"));
```

**B. In `deleteTabData` method:**
*Find this (around line 271):*
```java
    Integer deleteId = Integer.valueOf(String.valueOf(data.get("value")));
```
*Replace with:*
```java
    Integer deleteId = centralizedSecurityValidator.validateDeleteAccess(data.get("value"), user);
```

### 3. `Lfar2_1ServiceImpl.java` (Fixes Issues 3, 4, 7, 11)

**A. In `getData` method:**
*Find this (around line 50):*
```java
    String submissionId = String.valueOf(data.get("submissionId"));
    String reportId = String.valueOf(data.get("reportId"));
```
*Replace with:*
```java
    String submissionId = centralizedSecurityValidator.validateSubmissionAccess(data.get("submissionId"), user);
    String reportId = centralizedSecurityValidator.sanitizeId(data.get("reportId"));
```
*(Note: Because `submissionId` is now validated at the very top, it automatically clears Issues 3, 4, and 7 which use this variable later in the method).*

**B. In `deleteData` method:**
*Find this (around line 211):*
```java
    Map<String, Object> data = (Map<String, Object>) map.get("data");
    log.info("Delete data payload : " + data);
    int deleteId = Integer.parseInt(String.valueOf(data.get("value")));
```
*Replace with:*
```java
    Map<String, Object> data = (Map<String, Object>) map.get("data");
    Map<String, String> user = (Map<String, String>) map.get("user"); // Add user extraction
    log.info("Delete data payload : " + data);
    
    int deleteId = centralizedSecurityValidator.validateDeleteAccess(data.get("value"), user);
```
