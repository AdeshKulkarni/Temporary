Great observation!  
This is a **common Quill bug** when using custom embeds (blots):  
- If you insert a blot (like your `VariableBlot`) and then undo, Quill sometimes leaves a remnant node, often with its `firstChild.innerText` as `"true"` (or similar), instead of fully removing the blot.

**Why does this happen?**  
- Quill’s undo stack can sometimes misinterpret custom blots, especially if they’re inserted rapidly or their value is not a string.
- If your VariableBlot is created with a non-string value (e.g. accidentally `true` instead of `{{DATE}}`), `node.firstChild.innerText` will be `"true"`.

---

## **How to Fix**

### 1. **Force value to always be a string when creating the blot**

Update your `VariableBlot.create` to ensure `value` is always a string:

```js
static create(value) {
  value = String(value); // <--- Ensure value is always a string!
  const node = super.create();
  node.setAttribute("contenteditable", "false");
  node.classList.add("variable-blot");
  const text = document.createElement("span");
  text.innerText = value;
  const closer = document.createElement("span");
  closer.innerText = "X";
  closer.classList.add("variable-delete-icon");
  node.appendChild(text);
  node.appendChild(closer);
  Object.assign(node.style, {
    position: "relative",
    color: "black",
    padding: "5px 20px 5px 8px",
    margin: "0 4px",
    cursor: "default",
    userSelect: "none",
    display: "inline-block",
  });
  return node;
}
```

### 2. **Guard against non-variable blots when rendering or parsing**

In your code where you process variable blots (e.g. during preview, save, etc), **ignore any blots whose value is `"true"` or not in your variable list**.

Example:

```js
const variableBlots = tempDiv.querySelectorAll(".variable-blot");
variableBlots.forEach((blot) => {
  const variableName = blot.textContent.replace("X", "").trim();
  // Only replace if variableName is in draftVar
  if (draftVar.includes(variableName)) {
    // do your replacement
  } else {
    // Optionally remove blot or replace with empty string
    blot.replaceWith(document.createTextNode(""));
  }
});
```

### 3. **(Advanced) Clean up "true" nodes on undo**

Add a cleanup effect after each change in the editor, removing any `.variable-blot` elements whose text is `"true"`:

```js
useEffect(() => {
  const quill = bodyEditorRef.current?.getEditor();
  if (!quill) return;
  const cleanupTrueBlots = () => {
    const root = quill.root;
    root.querySelectorAll(".variable-blot").forEach(node => {
      if (
        node.firstChild &&
        node.firstChild.innerText === "true"
      ) {
        node.parentNode && node.parentNode.removeChild(node);
      }
    });
  };
  quill.on('text-change', cleanupTrueBlots);
  return () => quill.off('text-change', cleanupTrueBlots);
}, []);
```

## **Summary**
- Always `String(value)` in `create` for your custom Quill blot.
- Clean up any `.variable-blot` nodes with `"true"` text after undo or change.
- Filter out and ignore `"true"` variable blots during processing.
