# Implementation Guide: Centralized Security Validator (Part 2)

Apply these updates to your `saveData` and remaining delete methods to clear the rest of the Data Flow vulnerabilities.

### 1. `Lfar2ServiceImpl.java` (Fixes Issues in `saveData`)

**A. In `saveData` method:**
*Find this (around line 1026):*
```java
    // Fetch Data from Payload
    String submissionId = String.valueOf(data.get("submissionId"));
```
*Replace with:*
```java
    // Fetch Data from Payload (Use Validator)
    String submissionId = centralizedSecurityValidator.validateSubmissionAccess(data.get("submissionId"), user);
```
*(This clears the taint for `getDataIdMap(submissionId)` and `getRowIdBySubmissionId(submissionId)` sinks).*
