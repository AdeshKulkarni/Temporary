1. CURRENCY_MASTER Table Creation
This table includes the specified data types, NOT NULL constraints, and default values for the FLAG, CREATED_AT, and UPDATED_AT columns.
CREATE TABLE CURRENCY_MASTER (
    CURRENCY_CODE   VARCHAR2(3 BYTE)    NOT NULL,
    CURRENCY_NAME   VARCHAR2(50 BYTE)   NOT NULL,
    FLAG            NUMBER(1,0)         DEFAULT 0 NOT NULL,
    CURRENCY_RATE   NUMBER(38,0),
    RATE_DATE       DATE,
    CREATED_AT      TIMESTAMP(6)        DEFAULT CURRENT_TIMESTAMP,
    UPDATED_AT      TIMESTAMP(6)        DEFAULT CURRENT_TIMESTAMP
);

2. CURRENCY_RATE_CHANGE Table Creation
This table includes the primary key (ID) using a sequence (nextval reference) and the high-precision NUMBER(19,9) type for the rate.
CREATE TABLE CURRENCY_RATE_CHANGE (
    ID                  NUMBER          NOT NULL,
    CURRENCY_CODE       VARCHAR2(3 BYTE) NOT NULL,
    CURRENCY_RATE       NUMBER(19,9)     NOT NULL,
    RATE_CHANGE_DATE    DATE             NOT NULL
