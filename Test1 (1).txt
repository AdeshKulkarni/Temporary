I completely understand the problem. I looked at the screenshot, and the issue is that you are likely using a generic absolute Box, Tooltip, or an unconfigured Popper for the "Show More" popup. Because it doesn't know where the edge of the screen is, it just keeps expanding to the right and gets cut off.
To fix both issues (the popup going off-screen AND adding a "Show More" for the Description field), the cleanest React/Material-UI approach is to create a small, reusable ExpandableText component using MUI's Popover.
Popover is strictly better than Popper here because it automatically detects the screen edges and flips or shrinks itself so it never goes out of bounds.
Here is exactly what to replace in your file. I will not give you the whole file, just the snippets.
Step 1: Add Popover to your imports
At the very top of your file, find your @mui/material import and add Popover:
import {
  // ... your other imports ...
  Popover 
} from "@mui/material";

Step 2: Paste this reusable component
Paste this completely new component outside and just above your main function component (e.g., just above export default function VoucherActionController() { ... }).
// Add this right above your main component
const ExpandableText = ({ text, maxLength = 50 }) => {
  const [anchorEl, setAnchorEl] = useState(null);

  if (!text) return null;

  // If text is short, just show it normally
  if (text.length <= maxLength) {
    return <Typography variant="body2">{text}</Typography>;
  }

  const handleClick = (event) => {
    setAnchorEl(event.currentTarget);
  };

  const handleClose = () => {
    setAnchorEl(null);
  };

  const open = Boolean(anchorEl);

  return (
    <Box>
      <Typography variant="body2" sx={{ display: 'inline' }}>
        {text.substring(0, maxLength)}...
      </Typography>
      <Typography
        variant="body2"
        color="primary"
        sx={{ display: 'inline', cursor: 'pointer', ml: 0.5, fontWeight: 'bold' }}
        onClick={handleClick}
      >
        Show more
      </Typography>
      
      {/* Popover automatically prevents going off-screen */}
      <Popover
        open={open}
        anchorEl={anchorEl}
        onClose={handleClose}
        anchorOrigin={{
          vertical: 'bottom',
          horizontal: 'left',
        }}
        transformOrigin={{
          vertical: 'top',
          horizontal: 'left',
        }}
        slotProps={{
          paper: {
            sx: {
              maxWidth: { xs: '90vw', sm: 400 }, // Ensures it never exceeds screen width
              maxHeight: 300, // Adds a scrollbar if the text is massive
              p: 2,
              boxShadow: 3,
              overflowY: 'auto',
              wordWrap: 'break-word' // Forces long words to wrap instead of pushing the box wide
            }
          }
        }}
      >
        <Typography variant="body2" sx={{ whiteSpace: 'pre-wrap' }}>
          {text}
        </Typography>
      </Popover>
    </Box>
  );
};

Step 3: Replace your TableCells
Now, go down to your TableBody where you are rendering the rows (inside the Voucher Request Details box).
Instead of using your old "Show More" logic or printing the raw description, just wrap the variables in the <ExpandableText /> component.
For your Description column, replace it with this:
<TableCell>
  <ExpandableText text={row.description} maxLength={50} />
</TableCell>

(Note: Change row.description to whatever your exact variable name is, like row.acDesc or row.creditDesc)
For your Remarks column (the one from your screenshot), replace it with this:
<TableCell>
  <ExpandableText text={row.remarks} maxLength={50} />
</TableCell>

Why this fixes everything:
 * Fits the Screen: Because of maxWidth: { xs: '90vw', sm: 400 } and MUI's Popover engine, if the box hits the right edge of your monitor, it will automatically wrap the text onto the next line instead of going off-screen.
 * Scrollable: If the Description is 500+ characters, the popup won't take up the whole screen height. It will stop at 300px height and give the user a neat little scrollbar.
 * Reusable: You can now use <ExpandableText /> on literally any column in your app that has too much text!
