I apologize for the confusion! Let me make this extremely simple and clear.
The React file you shared earlier (VoucherPosting.jsx) is the Maker screen (where the user uploads the Excel file).
The Accept and Reject buttons do not exist in that file. They exist in your Checker/Inbox screen (usually named something like VoucherInbox.jsx, VoucherApproval.jsx, or CheckerDashboard.jsx).
You need to open that Checker/Inbox file, find where your Accept and Reject buttons are, and add one small condition around them.
What to find in your Frontend Checker File:
Look for your existing Accept and Reject buttons. They probably look something like this:
{/* YOUR EXISTING CODE LOOKS SOMETHING LIKE THIS: */}
<Button onClick={() => handleApprove(row)}>Accept</Button>
<Button onClick={() => handleReject(row)}>Reject</Button>

What to replace it with:
Copy this exact code and paste it over your existing Accept and Reject buttons.
(Note: Change row.workflowHistory to whatever your variable name is for the row data, and change handleApprove to whatever your actual approve function is called).
{/* REPLACE YOUR ACCEPT/REJECT BUTTONS WITH THIS: */}

{row.workflowHistory && row.workflowHistory.length > 0 && row.workflowHistory[row.workflowHistory.length - 1].actionType === "Execution Failed" ? (
    
    /* 1. IF IT FAILED: Show only the Retry button */
    <Button 
        variant="contained" 
        color="warning" 
        onClick={() => handleApprove(row)} /* Note: Retry triggers the exact same Approve function! */
    >
        Retry Approval
    </Button>

) : (
    
    /* 2. IF NORMAL: Show the standard Accept and Reject buttons */
    <div style={{ display: 'flex', gap: '8px' }}>
        <Button 
            variant="contained" 
            color="success" 
            onClick={() => handleApprove(row)}
        >
            Accept
        </Button>
        
        <Button 
            variant="contained" 
            color="error" 
            onClick={() => handleReject(row)}
        >
            Reject
        </Button>
    </div>

)}

How this works instantly:
Because we changed the backend to log "Execution Failed" in the Workflow History, this small React condition checks the history.
 * If the last word is "Execution Failed", it automatically hides the Accept/Reject buttons and shows the orange Retry Approval button.
 * When the user clicks Retry, it just calls your normal Approve API again!
